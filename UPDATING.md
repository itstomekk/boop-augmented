# Updating

1. Change the game in `docs/` (rules in `docs/logic.js`, UI in `docs/ui.js`).
2. Run `node test/logic.test.js` and `python test/browser_test.py`. Both must end with PASS.
3. If the look changed, copy the fresh board crops from `test/screens/board-desktop-*.png` to `.github/readme/` (classic-3d, classic-2d, big-2d, big-3d) and the mobile shot to `.github/readme/mobile-3d.png`.
4. Commit and push to `main`.
